# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use the
repository owner's GitHub profile to make private contact until GitHub private
vulnerability reporting is enabled for the repository.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Please avoid accessing data that is not your own while testing.

## Scope

Slackinux embeds Slack Web in WebKitGTK. Vulnerabilities in Slack itself should
be reported to Slack through its official security channels. Reports about the
Slackinux shell, navigation policy, local data handling, packaging, or native
integration belong here.
